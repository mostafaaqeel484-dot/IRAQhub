# IRAQhub 4.0 · خيارات 4:2:2 و4:2:0 ودقات متعددة مع HW / SW

## النطاق
التحديث مبني على إصلاح PR #37 (SurfaceHolder وFILE_LOADED) ويخص **المشغل المستقل** فقط، وليس LibVLC ولا tuner ولا CA/BISS. لا يتم تغيير MPEG-TS الأصلي. يفك libmpv/FFmpeg ضغط فيديو المصدر (مثل 1080p yuv422p10) أولاً، ثم يمكن تطبيق فلتر مخرجات الصورة. تخفيض الدقة بعد الفك لا يقلل بالضرورة عبء فك المصدر على CPU، بل قد يرفع كلفة swscale.

## اختيار Format/Resolution من الريموت
- Auto 4:2:0: يبدأ 1280×720 ثم 960×540 ثم 640×360 عند إثبات تكرر إسقاط VO، بحد أقصى خطوتين داخل الجلسة (لا يوجد تغيير أثناء البث إلا عبر إعادة فتح نفس relay).
- YUV 4:2:0 / 8-bit: 1920×1080، 1280×720، 960×540، 854×480، 640×360.
- YUV 4:2:2 / 10-bit: 1920×1080، 1280×720، 960×540، 854×480، 640×360.
- GPU native: بدون فلتر تحويل CPU، للمقارنة وللتعافي من فشل إعداد الفلتر.
- التغيير يتم عبر `vf=lavfi=[scale=...,format=pix_fmts=...]` بعد فك المصدر.

## HW / SW
- SW (الافتراضي): `hwdec=no`؛ الخيار الأكثر قابلية للتنبؤ لفيد 4:2:2 10-bit.
- HW التجريبي: `hwdec=mediacodec-copy`. دعم MediaCodec على X5M لصيغة 4:2:2 غير مثبت وقد يرفض التشغيل أو يرجع MPV تلقائياً إلى SW.
- عند فشل بدء المحرك أثناء اختيار HW، يحاول البرنامج **مرة واحدة فقط** بفك SW على نفس رابط MPEG-TS؛ بعدها محاولة GPU native مرة واحدة عند تعذر فتح فلتر العرض. لا يعاد توليف القمر أو إغلاق TS relay أو التلاعب ببرمجيات النظام.
- `hwdec-current` في Stats هو مصدر حقيقة ما إذا كان فك الفيديو العتادي مستخدماً فعلياً، وليس مجرد زر الاختيار. إن لم تتوفر الخاصية تظهر UNAVAILABLE.
- ليس هناك إجبار `gpu-context=android` ولا `opengl-es` عند البداية؛ لأن هذه الإعدادات سبقت عطل FILE_LOADED في PR #36.

## اختبار أجهزة X5M
1. تأكد من نسخة البناء والتوقيع وأخذ نسخة احتياطية قبل تثبيت Debug؛ توقيع Debug ليس بالضرورة توقيع Release الحالي.
2. جرّب المصدر نفسه في `SW / 420 720p`، ثم `SW / 420 540p`، ثم `SW / 420 360p`.
3. جرّب `SW / 422 720p` و`SW / 422 540p` و`SW / 422 360p`، ثم GPU native. لاحظ جودة الألوان والحركة، وليس الساعة فقط.
4. جرّب HW اختياريًا: اقرأ `hwdec-current`; إذا كانت `no` فهذا فك SW حتى لو اخترت HW.
5. قارن لقطة 30 ثانية ثم اختبار 10 دقائق بنفس الفيد: تحرك الصورة بعينك، معدل الإطارات، VO dropped لكل فترة، CPU، التزامن، وتأثير فلتر 422/420.
6. إذا ظهرت شاشة سوداء، افتح Stats وانسخ `MPV_START` و`event/surface/command/vf/native`، أو `adb logcat -d -s IRAQhub422 AndroidRuntime` من اتصال مصرح به.
