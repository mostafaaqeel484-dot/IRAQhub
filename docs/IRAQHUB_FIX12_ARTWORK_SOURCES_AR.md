# إصلاح 12 — مصادر شعارات وبوسترات IRAQhub 4.0.0-alpha1

توسعة PR #26 دون دمجه. لا يصح اعتبار نجاح اختبارات Android دليلاً على نجاح تحميل الصور من جميع المواقع على X5M.

## المصادر الثلاثة
1. **TVmaze** — https://www.tvmaze.com/api : صور المسلسلات، وصورة الحلقة فقط عند وجود اسم مسلسل مطابق بلا التباس + SxxExx. يستخدم البحث المحدد وكاش 12 ساعة، ويتعامل مع HTTP 429 بالتأجيل 60 ثانية. لا تُستخدَم ملصقات المسلسلات كشعارات لقنوات DVB.
2. **TheSportsDB Free v1** — https://www.thesportsdb.com/documentation : المفتاح العام 123 و `https://www.thesportsdb.com/api/v1/json/123/`. طلبات الـAPI محدودة بحد أقصى 30/دقيقة من هذا التطبيق عبر انتظار 2.2 ثانية مع نافذة متحركة 60 ثانية، مع كاش وتمييز HTTP 429. نتائج بعض endpoints في المجاني محدودة؛ لا يتيح المفتاح Premium v2. صور الفرق والبطولات والأحداث تُستخدم مع الهوية الرياضية المؤكدة؛ يوجد بحث يدوي بالاسم عن شعار فريق وصورة لاعب، وليس ربطاً تخمينياً بقناة.
3. **Wikimedia Commons** — https://commons.wikimedia.org/wiki/Commons:API : مدخل لصورة محددة بعنوان `File:`. تحقق من نوع الصورة والـHTTPS ومعلومات `LicenseShortName` و`Artist` و`Credit` و`LicenseUrl` وصفحة الملف. لا تُقبل صور NC/ND أو بدون ترخيص معروف. تحفظ بيانات النسبة باسم القناة الفعلي أو هوية بث EPG الحالي/التالي الدقيقة.

## الاستخدام
- من **شعارات القنوات** أو **تشخيص البوسترات** أو **إعدادات InfoBar** افتح **«إصلاح 12 · مصادر الشعارات والبوسترات»**.
- فعّل/عطّل كل مصدر؛ لفحص صورة لاعب أو فريق أدخل الاسم الدقيق ثم استخدم الفحص اليدوي.
- للصورة الحرة أدخل عنوان ملف Commons `File:...` حرفياً، اختر «شعار القناة» أو «بوستر الآن» أو «بوستر التالي». لن يرتبط البوستر ما لم يكن للبرنامج هوية EPG/وقت بداية حقيقي.
- الزوايا: بوستر الآن أعلى اليسار، بوستر التالي أعلى اليمين، وInfoBar أسفل الشاشة؛ الصور لا تظهر إلا بعد نجاح التحقق والتنزيل.
- أثناء software DVB 4:2:2 تؤجل الشبكة وتستخدم الصور المخزنة، حماية لأولوية تشغيل الفيديو.

## الحدود
- العمل لا يمنح ADB أو صلاحيات OEM ولا يصلح وحده تجمد 4:2:2 بعد أول إطار.
- الربط اليدوي لشعار قناة لا يفك تشفيرها ولا يقرأ قاعدة بيانات المصنع الخاصة.
- الإسناد والترخيص يعرضان في صفحة المصادر؛ تحقق من صفحة Commons لكل ملف قبل إعادة التوزيع، بما في ذلك حقوق العلامات والأشخاص.
- ينبغي قياس زمن أول شعار/بوستر على الجهاز الحقيقي قبل الادعاء بتحسن مقداره معلوم.
