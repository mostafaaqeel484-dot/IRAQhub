# IRAQhub 3.7.3 — أول إصدار تجريبي لـ Amlogic X5M

**التاريخ:** 7 نوفمبر 2026  
**النظام المستهدف:** Android 14 / Amlogic X5M / 4GB LPDDR4  
**الحزمة:** `com.smarthub.plus`  
**الإصدار داخل التطبيق:** `3.7.3`

> **تحذير مهم:** هذه أول نسخة GitHub Release **تجريبية (Pre-release)**. نجحت اختبارات Java/Kotlin وبناء Debug/Release داخل GitHub Actions، لكن **لم يثبت تشغيل البحث اليدوي الحقيقي أو فيديو 4:2:2 10-bit أو CHMAX أو اللوحة الأمامية على الرسيفر الفعلي بعد**.

## التحسينات

- تشغيل DVB و4:2:2: الإبقاء على مسارات Media3 وLibVLC / FFmpeg الاحتياطية، ومنع مهام الصور الثقيلة من التأثير على الأداء أثناء البث.
- البحث اليدوي DVB-S/S2: فحص PAT/PMT/SDT من TS فعلي إذا سمح Firmware بذلك، وتسجيل مراحل التقاط TS وأخطاء `tp_record=1` لاختبار المشكلة.
- فحص الجهاز: صفحة لنسخ/مشاركة تقرير Decoder والإطارات الساقطة، البحث اليدوي، EPG والبوسترات وCHMAX، بدون حفظ أسرار BISS.
- قوائم القنوات: وضع Aurum ووضع DVB وظيفياً، وتثبيت القناة المحددة عند التبديل، ودعم GUIDE/SEARCH/MENU.
- قواعد SQLite: استيراد Aurum الكامل أو دمجها بعد معاينة؛ الدمج يحافظ على القنوات الحالية وترتيبها والمفضلة ويستخدم هوية التردد + SID.
- EPG: فهرس محلي لأحداث EPG المتحقق منها وتقديم معلومات البرامج للقنوات أثناء انقطاع الإنترنت.
- شعارات CHMAX/Aurum: تخزين الصور المرصودة في مساحة تطبيق دائمة، وتحسين سلامة ومطابقة الشعار.
- تحسين التنقل بين أكثر من 10,000 قناة بتخزين مؤقت قصير لفهرس القنوات.

## ملفات APK

- **`IRAQhub_3.7.3_FourStage_X5M_Debug.apk`**: نسخة Debug موقّعة بمفتاح تجريبي خاص بتشغيل CI، للاختبار فقط. **لا يُعتمد على ثبات هذا المفتاح بين الإصدارات.**
- **`IRAQhub_3.7.3_FourStage_X5M_Release_UNSIGNED.apk`**: نسخة Release غير موقّعة؛ **لا يمكن تثبيتها كتحديث مباشر** حتى تُوقّع بمفتاح إنتاج يملكه المطور.
- ملف `SHA256SUMS.txt` يحتوي بصمات الملفات للتحقق من سلامة النقل.

**قبل التثبيت:** احفظ نسخة من DB وإعداداتك، ولا تحذف التطبيق القديم أو بياناته بسبب اختلاف التوقيع قبل التأكد من إمكان استعادتها. لا تثبت ملف Release غير الموقّع.

## حدود النسخة

1. `tp_record=1` قد يرفضه Firmware: البحث اليدوي المباشر **غير مضمون** حتى بعد نجاح البناء؛ fallback إلى OEM أو DB المصدّرة ليس بديلاً عن إثبات المحرك المستقل.
2. HEVC Main10 لا يثبت دعم Hardware 4:2:2 10-bit. يجب تجربة H.264/HEVC بث واقعي وألوان/صوت متزامنين لمدة مطوّلة.
3. EPG Pro الكامل وCHMAX يتطلبان دعم الواجهات والمصادقة والتطابق الفعلي بالمصادر، وليس وجود الكود فقط.
4. التحكم بشاشة الرسيفر الأمامية لم يُفعّل لعدم وجود واجهة OEM مثبتة.
5. قوائم Aurum تستخدم سلوكيات مماثلة في IRAQhub، وليس تطابقاً كاملاً مثبتاً بالهندسة العكسية لكل أوامر OEM.
