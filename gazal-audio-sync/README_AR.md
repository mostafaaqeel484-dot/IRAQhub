# Gazal Audio Sync — نسخة تجريبية مستقلة

مشروع Android نظيف، مبني على معلومات هندسة عكسية وظيفية لتطبيق BEN10 لكن لا يحتوي على مكتباته أو نظام ترخيصه أو محتويات core.b10.

## ما يعمل في هذا الإصدار
- شاشة Android TV عربية/إنجليزية موجهة للريموت.
- استيراد قوائم M3U/M3U8/CFG النصية التي تحتوي روابط HTTP(S) واضحة.
- إضافة مصدر صوت يدوي، حفظ مصادر الصوت، وتشغيل رابط صوت خارجي باستخدام Android MediaPlayer في Foreground Service.
- شريط عائم فوق فيديو Aurum **بعد موافقة المستخدم** على صلاحية الظهور فوق التطبيقات.
- إيقاف/استئناف/تبديل المصدر؛ وفاصل بدء اختياري قبل بدء التشغيل (ليس مزامنة PCM دقيقة).
- فحص قراءة فقط لوجود /dev/dvb0.demux6 و/dev/dvb0.dvr6 وبيانات PID ومنفذ ADB المحلي.

## حدود مهمة
- **لم يتم تنفيذ تأخير فيديو DVB الحقيقي حتى الآن**. يحتاج Aurum أو DTVKit API يعمل على جهاز Gazal ويمكنه timeShiftPause/timeShiftResume، أو مسار موثوق لإرجاع TS مؤخر. الواجهة الحالية لا تعد بتشغيل TimeShift الفيديو.
- خيار تأخير بدء تشغيل الصوت ليس بديلاً عن buffer PCM أو مزامنة timestamp دقيقة. قد لا تعمل روابط HLS الحية إذا كان الخادم يتطلب مصادقة أو headers أو DRM.
- لا يصلح كبديل كامل لـ BEN10، لكنه تطبيق يمكن اختبار تشغيله بصورة مستقلة دون تفعيل.
- لا يكتب في عقد DVB، ولا ينفذ أوامر ADB تلقائياً، ولا يمنح لنفسه صلاحيات.
- اختبر على قناة FTA واضبط صوت DVB من الريموت؛ التطبيق لا يكتم صوت القناة بالقوة.

## البناء
Android Studio / Gradle 8.9+، JDK 17، Android SDK 35:
`gradle assembleDebug` داخل مجلد gazal-audio-sync.

ملف الاختبار المتوقع: `app/build/outputs/apk/debug/app-debug.apk`.
حزمة التطبيق: `com.gazal.audiosync` منفصلة تماماً عن BEN10، فلا تحتاج حذف النسخة السابقة.

## ملاحظات الاختبار
مكتبة Gazal المبلغ عنها متوافقة بالمسارات، لكن نجاح الفتح/الالتقاط من Native غير مثبت. هذا المشروع يركز على تشغيل صوت الإنترنت والواجهة العائمة إلى أن يتوفر تكامل DVB موثق.
