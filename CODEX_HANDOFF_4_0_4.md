## Build/test recipes
Use Gradle 8.11.1, JDK 21, compileSdk 36, build-tools 35.0.0, NDK r29 `29.0.14206865`, CMake 3.22.1.

```sh
gradle :app:testDebugUnitTest --no-daemon
gradle :app:assembleDebug --no-daemon
bash scripts/build-native422-ffmpeg.sh "$PWD/.native422/ffmpeg-armv7"
gradle :app:assembleNative422Preview -Pnative422FfmpegRoot="$PWD/.native422/ffmpeg-armv7" --no-daemon
```

The last two steps require NDK/network access to pinned, PGP-verified FFmpeg source. The experimental JNI build ships only ARMv7, and packages external MPV/LibVLC runtimes.

### Packaging caution
